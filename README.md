# Zapret Launcher

Простое приложение для Windows, которое включает [zapret](https://github.com/bol-van/zapret) в один клик.
Один маленький установщик `ZapretLauncherSetup.exe` — больше ничего не нужно.

*A tiny one-file Windows app that downloads and runs zapret (DPI bypass) with one click.*

## Как это работает

1. Запустите `ZapretLauncherSetup.exe` и пройдите установку (потребуются права администратора — их требует драйвер WinDivert).
2. При первом запуске приложение само скачает свежую сборку [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) с GitHub в `%LOCALAPPDATA%\ZapretLauncher`.
3. Нажмите большую кнопку питания. Если что-то не открывается — нажмите «Автоподбор»: приложение по очереди проверяет все стратегии, отмечает в списке галочкой те, с которыми открываются YouTube и Discord, и включает первую из них. Любую другую отмеченную можно выбрать вручную.

Дополнительно:

- **Игровой фильтр** — расширяет обход на игровые порты.
- **Запускать вместе с Windows** — создаёт задачу планировщика с повышенными правами: приложение стартует в трее, сразу включает обход и не показывает окно UAC.
- **Обновить** — скачивает новую версию компонентов; ваши файлы `*user*.txt` в `lists` сохраняются.
- Если включено «Сворачивать в трей» (по умолчанию да), при закрытии окна приложение остаётся в трее. Выход — через значок в трее.

Рядом с exe приложение ничего не создаёт: все данные лежат в `%LOCALAPPDATA%\ZapretLauncher`.
Удаляется программа через «Установка и удаление программ» в параметрах Windows.

## Вкладка TG WS Proxy

Вторая вкладка вверху окна — [TG WS Proxy](https://github.com/Flowseal/tg-ws-proxy): локальный прокси, через который Telegram на этом компьютере ходит к своим серверам по WebSocket.

Нужно одно нажатие: откройте вкладку и нажмите кнопку питания. Прокси запустится, а Telegram откроется с предложением его подключить — останется подтвердить. Это делается один раз; дальше Telegram ходит через прокси сам, пока тот включён.

Сам прокси установщик скачивает с GitHub в `%LOCALAPPDATA%\ZapretLauncher\tgws` вместе с компонентами zapret. Настраивать ничего не надо: адрес, порт и ключ лаунчер берёт стандартные (если порт занят — подбирает свободный) и пишет их в `config.json` прокси.

- **Резерв через Cloudflare**, **Ускорение медиа** — настройки самого прокси; работающий прокси перезапускается с ними сам.
- **Включать с лаунчером** — прокси стартует вместе с приложением.
- **Подключить** — заново предлагает прокси Telegram; **Скопировать ссылку** — то же самое ссылкой, если Telegram не открылся.
- **Не грузятся медиа** — если сообщения ходят, а фото и видео нет: каждое нажатие включает следующий из трёх способов соединения с серверами Telegram.

Работает ли обход и прокси, видно по белой точке у названия вкладки и по значку в трее: он один на двоих и горит, пока включено хоть что-то. Своего значка у прокси нет — лаунчер запускает его на отдельном, невидимом рабочем столе Windows. Если так он не запустится, лаунчер запустит его обычным образом, и тогда значок прокси в трее появится.

## Вкладка «Настройки»

Всё, что настраивается, собрано на третьей вкладке; на первых двух остались только кнопка включения и то, что нужно каждый день.

- **Zapret** — игровой фильтр и кнопки своих списков (`*user*.txt`).
- **Прокси Telegram** — резерв через Cloudflare, ускорение медиа, запуск вместе с лаунчером, «Не грузятся медиа», логи и папка.
- **Приложение** — сворачивание в трей и запуск вместе с Windows.
- **Оформление**:
  - **Фон** — своя картинка вместо звёзд (JPG, PNG, BMP, GIF, TIFF). Она растягивается на всё окно с сохранением пропорций, лишнее по краям обрезается, и слегка затемняется, чтобы текст оставался читаемым. Лаунчер хранит свою копию в `%LOCALAPPDATA%\ZapretLauncher`.
  - **Размытие стекла** — от 0 (панели прозрачные) до 100%; по умолчанию 60%.
  - **Акцентный цвет** — восемь готовых цветов или свой в виде `#RRGGBB`. Им окрашены кнопка включения, точки-индикаторы, переключатели, полосы выбора и прогресса.

## Установщик

`ZapretLauncherSetup.exe` — это тот же exe под другим именем. Любая копия, которая не является установленной, при запуске открывает мастер установки.
Мастер копирует лаунчер в выбранную папку (по умолчанию `C:\Program Files\Zapret Launcher`), создаёт ярлыки, регистрирует программу в «Установка и удаление программ» и сразу скачивает компоненты zapret и прокси для Telegram.

Установщик не ставит устаревшую версию: перед установкой он проверяет, не вышла ли версия новее, и если вышла — скачивает её установщик и продолжает уже им, с теми же выбранными папкой и переключателями. Это умеют установщики начиная с версии 1.2.1; более ранние ставят ту версию, которая в них лежит. Всегда свежий установщик — по ссылке https://github.com/pikacu1337/ZapretLauncher/releases/latest/download/ZapretLauncherSetup.exe.

Удаление — через параметры Windows (или `ZapretLauncher.exe --uninstall`). Мастер удаления спрашивает, сохранить ли настройки, ваши списки `*user*.txt` и настройки прокси для Telegram.
Запустить без установки можно только с ключом `--portable` (нужно для разработки): `ZapretLauncher.exe --portable`.

## Важно

- Антивирусы иногда ругаются на `winws.exe` и `WinDivert` (это легитимные инструменты перехвата трафика, но они похожи на «хакерские»). Если файлы удаляются, добавьте папку `%LOCALAPPDATA%\ZapretLauncher` в исключения.
- На `TgWsProxy.exe` антивирусы тоже могут реагировать: он собран PyInstaller'ом, а такие файлы часто попадают под ложные срабатывания. Если прокси не скачивается или сразу закрывается, причина обычно в этом.
- Для разбора стратегий приложение читает `.bat`-файлы из сборки Flowseal. Если автор сильно поменяет формат этих файлов, парсер в `Core.cs` (`Engine.BuildArgs`) придётся поправить.
- Автоподбор — эвристика: он проверяет, что отвечают YouTube и Discord. На разных провайдерах результат может отличаться.
- Это независимый проект, он не связан с авторами zapret и zapret-discord-youtube. Используйте на свой риск и с учётом законов вашей страны.

## Сборка

Нужен [.NET SDK](https://dotnet.microsoft.com/download) 6+ на Windows:

```
dotnet build ZapretLauncher.csproj -c Release -o out
```

Рядом появится `out/ZapretLauncherSetup.exe` — установщик (копия того же файла).
Раздавать нужно только `out/ZapretLauncherSetup.exe` (приложение собрано под .NET Framework 4.8, он встроен в Windows 10/11).

### Релиз через GitHub Actions

Любой push в `main` собирает exe (вкладка Actions → Artifacts). Чтобы выпустить релиз:

```
git tag v1.0.0
git push origin v1.0.0
```

Workflow сам соберёт exe и приложит его к релизу.
